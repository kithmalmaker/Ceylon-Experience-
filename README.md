# 🌴 Ceylon Experience — Sri Lanka Tours & Transfers Website

Official modern, responsive, and bilingual website for **Ceylon Experience** (Kalutara, Sri Lanka).

## 🚀 Features
- **Bilingual Support:** Instant switching between English (🇬🇧) and Russian (🇷🇺).
- **Fleet Showcase:** Authentic Red Bajaj RE Tuk-Tuk and Toyota Hiace Luxury A/C Van (1–9 Passengers with luggage).
- **Tour Packages:** Kalutara Heritage, Madu River Mangrove Safari, Galle Dutch Fort, Mirissa Whale Watching, Udawalawe Elephant Safari, and 24/7 Colombo Airport Transfers.
- **WhatsApp-First Booking:** One-click instant booking messages formatted in the user's selected language.
- **Mobile-First UX:** Sticky quick action bar (Call & WhatsApp) and fast-loading responsive design.

## 📦 Deployment

### Deploy with Vercel
1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository (`ceylon-experience` or `kalutara-tours-website`).
4. Click **Deploy** — your live website will be generated in under 30 seconds!

### Run Locally
You can run a local server using Python:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.
